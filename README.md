# Document Validator

### Python | Document Analysis | Data Validation | Backoffice

A Python-based educational project focused on registration data validation, data quality, and operational process improvement.

## About the Project

Document Validator was created to demonstrate basic programming and analytical skills applied to document-related and backoffice workflows.

The project identifies formatting errors and inconsistencies in registration data using automated validation rules.

## Features

- Full name verification
- Email format validation
- CPF format and check-digit validation
- Identification of inconsistent records
- Structured validation results

## Technologies

- Python 3
- Regular Expressions (Regex)
- Google Colab
- GitHub

## How to Run

1. Open Google Colab.
2. Copy the code from `validator.py`.
3. Paste it into a code cell.
4. Run the cell to see the validation results.

## Important Notice

This is an educational project using fictional data.

It does not verify document authenticity, consult official databases, or perform identity verification.
